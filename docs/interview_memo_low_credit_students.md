# 単位未修得学生 面談メモ表
（春学期に単位を2つ以上落とした学生対象）

## 目的
- 単位を落とした背景・原因を学生と一緒に整理する
- 今後の学修計画を具体化し、行動につなげる
- 学生のモチベーションを引き出し、孤立させない
- 必要な支援（学習支援・経済支援・心理面のサポート等）につなげる

## 3. 面談前チェック事項（教員が事前に確認）

- [ ] 対象科目・単位数・成績を成績システムで確認した
- [ ] 出席状況（欠席・遅刻の傾向）を確認した
- [ ] 過去の面談記録・相談歴の有無を確認した
- [ ] 他科目の状況（他にも不振な科目がないか）を確認した

- [ ] 学生相談室・保健センター等の利用歴があるか確認した（分かる範囲で）

## 4. 面談中の質問リスト

### (1) 事実確認・振り返り（責めるのではなく事実整理として）
- [ ] この科目を履修していて、どのあたりから難しく感じ始めましたか？
- [ ] 授業には出席できていましたか？欠席が続いた時期はありましたか？
- [ ] 課題やテストへの取り組み方はどうでしたか？
- [ ] 分からないことがあったとき、質問や相談はできましたか？（教員・友人・TA等）

### (2) 生活面・環境面の確認
- [ ] 生活リズム（睡眠・食事など）に変化はありましたか？
- [ ] アルバイトやサークル活動との両立で負担を感じていましたか？
- [ ] 人間関係（友人・家族）で気になることはありましたか？
- [ ] 経済的な事情で学業に影響が出ていることはありますか？

### (3) 心身の健康・メンタル面
- [ ] 最近、気持ちが落ち込んだり、やる気が出ないことはありますか？
- [ ] 体調面で不安なことはありますか？
- [ ] 誰かに相談できている実感はありますか？

### (4) 今後に向けた対話（モチベーションを引き出す）
- [ ] この学科・分野に進んだきっかけや、興味を持っていることは何ですか？
- [ ] 今、一番関心がある授業や分野はありますか？
- [ ] 卒業後、将来やってみたいことはありますか？
- [ ] 秋学期、まず取り組んでみたいことを1つ挙げるとしたら何ですか？
- [ ] 今のあなたにとって、大学生活で大事にしたいことは何ですか？

### (5) 支援ニーズの確認
- [ ] 学習面でのサポート（学習支援室・チューター制度等）は必要そうですか？
- [ ] 学生相談室・カウンセリングの利用を検討したいですか？
- [ ] 経済的な支援（奨学金相談等）の情報が必要ですか？
- [ ] 履修計画について一緒に相談したい科目はありますか？
